# 星际突击 · STAR RAID（3D 版）

手机竖屏的 3D 空战射击游戏，画面用 Three.js（WebGL）实时渲染：倾斜镜头下的立体地形、立体的飞机和地面部队、光照、雾和天气。共 20 关，每关一个场景和一个 Boss，打完通关。

作者：蔡蕴文

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面、界面和样式 |
| `game.js` | 游戏逻辑和 3D 渲染 |
| `vendor/three.min.js` | Three.js r128（已放在仓库里，不需要联网） |
| `standalone.html` | 把上面三个文件合并成的**单个文件**，可以直接发给别人或拷到手机里打开 |
| `build.py` | 重新生成 `standalone.html`：`python3 build.py` |

## 运行

最简单：用浏览器直接打开 `standalone.html`。

或者在目录下起一个静态服务后访问 `index.html`：

```bash
python3 -m http.server 8000   # 手机和电脑同一网络时访问 http://<电脑IP>:8000
```

需要支持 WebGL 的浏览器（近几年的手机和电脑浏览器都支持）；不支持时页面会给出提示。桌面浏览器会以居中的竖屏比例显示，并支持键盘。

## 界面流程

- **登录界面**：背景是实时 3D 场景（20 个关卡轮流展示，战机在空中巡航）。在这里选择难度（简单 / 中等 / 困难，会记住上次选择），然后「开始出击」；还有高分榜、玩法说明、音效开关。
- **暂停菜单**（右上角 ⏸）：继续游戏 / 重新开始 / 高分榜 / 音效开关 / 结束游戏。
  - **重新开始**会先弹出难度选择，可以换一个难度再开始；点「取消」回到暂停菜单。
  - **结束游戏**会把当前得分记入高分榜，然后退回登录界面。
- **游戏结束界面**：「再来一局」同样先选难度；「返回登录界面」回到开头。
- **通关**：打败第 20 关的 Boss 后播放通关动画（全屏烟花，战机翻滚着加速冲出画面，飞回母星），然后显示通关画面：星级（一次没阵亡 3 星，阵亡 1–2 次 2 星，更多 1 星）、最终得分、用时、击毁数、最高连击和通关奖励分。高分榜里通关的记录会标注「通关」。

## 操作

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| 方向圆盘 | 左下角 | 模拟量移动，带惯性，平滑转向；机身中心可到屏幕边缘（半个机身出屏），能打到边缘的敌机 |
| **A** 射击 | 右下角 | 按住射击；**长按约 0.5 秒锁定连发**，锁定后**再按一次解除** |
| **B** 技能 | 右下角（A 正上方，A/B 半透明，飞机经过时更透明） | 能量满后释放「星爆」冲击波：**秒杀屏幕上除 Boss 以外的所有敌人**（Boss 受到重创）、清除全部敌弹和预警光束，并让自己**无敌 3 秒**（金色光罩，可用强化「星爆护体」延长） |
| 暂停 ⏸ | 右上角 | 打开暂停菜单 |

键盘：方向键或 WASD 移动，Space/J 射击，L 锁定连发，B/K/Shift 技能，1-4 切换弹种，P/Esc 暂停。

## 玩法

- **难度**：简单 5 条命、敌机更脆、敌弹更慢、掉落更多；中等 4 条命；困难 3 条命、敌机更多更硬、敌弹更快。高分榜会标注难度。
- **关卡**：一共 **20 关**，打完即通关，不再无限循环。每关 3 波：2 波敌人 + 1 个 Boss；场景和 Boss 每关都不同，敌人的种类、血量、弹速和 Boss 血量逐关略微增加。换关时有过渡。

  | 关 | 场景 | Boss |
  | --- | --- | --- |
  | 1 | 雪原冰川 | 极寒守卫 |
  | 2 | 樱花山谷 | 赤焰主宰 |
  | 3 | 黄沙戈壁 | 陆行堡垒（地面） |
  | 4 | 碧海群岛 | 雷霆战舰 |
  | 5 | 糖果乐园 | 果冻王 |
  | 6 | 翡翠丛林 | 蜂巢母舰 |
  | 7 | 赤霞峡谷 | 沙海巨蝎（地面） |
  | 8 | 水晶洞窟 | 晶簇女王 |
  | 9 | 熔岩火山 | 熔岩炎龙 |
  | 10 | 极光冰海 | 极光巨鲸 |
  | 11 | 幽灵沼泽 | 幽灵舰长 |
  | 12 | 深海遗迹 | 深海巨章 |
  | 13 | 云端天城 | 日月双子 |
  | 14 | 霓虹都市 | 裂空者 |
  | 15 | 钢铁工厂 | 齿轮巨像 |
  | 16 | 赛博网格 | 镜面魔方 |
  | 17 | 月面基地 | 轨道炮台 |
  | 18 | 深空轨道 | 虚空织网者 |
  | 19 | 虚空裂隙（黑洞） | 黑洞核心 |
  | 20 | 霸主旗舰 | 星际霸主（最终 Boss，三种形态） |

- **地面部队**（第 18、19 关的太空场景没有）：小炮台、坦克（海上、冰海、沼泽里是炮艇，第 3 关起）、电磁塔（第 4 关起：蓄能时出现光圈，随后向四周放出一圈电弧弹）、导弹车（第 5 关起）、高射炮（第 7 关起）。它们随地面靠近，可以被击毁，但不会和飞机相撞，也不能夺舍。
- **空中敌机**（21 种，新敌机首次登场时有名称提示，括号里是大约从第几关开始出现）：
  - 基础：侦察机、战斗机、重型炮艇、俯冲镖。
  - 分裂机（第 2 关）：被击毁后分裂成两架侦察机。
  - 狙击机（第 3 关）：红色瞄准线预警后射出高速重弹。
  - 陨石（第 3 关）：可击碎的障碍，会碎成两块，不能夺舍。
  - 运输机（第 3 关）：不开火，横穿屏幕逃跑；**击落必掉两个道具**。
  - 蜂群机（第 3 关）：成群追踪玩家的小型自杀机。
  - 布雷机（第 5 关）：投放水雷，水雷闪烁后爆裂成一圈子弹，可以提前击落。
  - 冲锋舰（第 5 关）：红色横线预警后高速横向冲撞。
  - 浮游炮台（第 5 关）：旋转着向四个方向开火。
  - 闪电机（第 5 关）：现身后三连射，然后瞬移到别处，五次后离场。
  - 护盾舰（第 6 关）：先要打破护盾。
  - 隐形机（第 7 关）：隐身时无法被锁定和命中，现身后扇形齐射。
  - 无人机母舰（第 7 关）：不断放出蜂群机，应优先击落。
  - 导弹艇（第 9 关）：发射可被击落的追踪导弹。
  - 修复机（第 9 关）：用光束修复附近受损的敌机。
  - 引力机（第 10 关）：把玩家拉向自己，并发射缓慢的重力弹。
  - 旋涡机（第 11 关）：喷出旋转的螺旋弹幕。
  - 激光舰（第 12 关）：红线预警后喷出竖直光束。
  - **精英 ★**（第 3 关起随机出现）：体型更大、更耐打、火力更密，得分 ×3，必掉道具。
- **Boss**（20 种，每关一个）：外形、移动方式和招式各不相同；半血后进入狂暴（出招更快并解锁额外能力），被击败时清空全屏敌弹。
  1. 极寒守卫：交错冰锥、暴风雪、冰环加冰矛；狂暴后屏幕两侧降下冰墙。
  2. 赤焰主宰：扇形弹、环形弹、三连点射；狂暴后两侧持续弹雨。
  3. 陆行堡垒：地面 Boss，高射炮齐射、追踪导弹、扇形扫射；飞机可以从它上方飞过。
  4. 雷霆战舰：从一侧依次落向另一侧的雷击光柱、四门舷炮齐射、放出浮游炮台；狂暴后朝你的位置落雷。
  5. 果冻王：在上半场弹来弹去；会分裂的果冻弹、碰到两侧会反弹的弹珠、召唤小果冻。
  6. 蜂巢母舰：放出蜂群机、追踪导弹、螺旋弹幕。
  7. 沙海巨蝎：地面 Boss，尾巴始终指向你；抛物线毒液、双钳交叉扫射、钻地突刺（地面先出现圆形预警）。
  8. 晶簇女王：水晶护卫绕身旋转，能挡住子弹（激光可以穿透）；悬停后射向你的晶刺、回旋晶环、反弹棱光。
  9. 熔岩炎龙：龙头带着一串身体游走，火焰吐息、全身齐射、喷发落石；身体也能被击中，碰到会受伤。
  10. 极光巨鲸：喷泉水柱（抛物线洒落）、带缺口的声波环（钻缺口躲避）、左右飘动的极光雨。
  11. 幽灵舰长：时隐时现，隐身时打不到；追踪鬼火（可击落）、从屏幕两侧横飞进来的舷炮、召唤隐形机。
  12. 深海巨章：触手横扫（横向光束，上下躲避）、缓慢的大墨团、漩涡弹幕；狂暴后把你往它身边吸。
  13. 日月双子：月亮绕着太阳转并自己开火，打月亮也算伤害；日冕环、日月交辉、日食（月亮轨道变大，扫过半个屏幕）。
  14. 裂空者：留缺口的弹墙、对准玩家俯冲、霰弹。
  15. 齿轮巨像：旋转的四臂弹幕（狂暴时中途反转）、在两侧墙壁间反弹的大齿轮、活塞重锤（落点预警）。
  16. 镜面魔方：在三个位置之间瞬移；折射光弹、纵横交错的光束网格、整块推进的方阵弹。
  17. 轨道炮台：轨道轰炸（一连串落点）、追踪导弹齐射、主炮（粗光束）加两翼扫射。
  18. 虚空织网者：带预警的竖直光束、抛射水雷、双层蛛网弹；狂暴后会瞬移。
  19. 黑洞核心：一直把你往它身边吸；旋臂星环（弧线弹）、引力弹团、从屏幕边缘向中心坍缩的弹幕（会从背后飞来）。
  20. 星际霸主：最终 Boss，血量每降三分之一换一种形态，三种形态共九种招式。
- **强化**：每击败一个 Boss，从三个随机强化里选一个，本局有效（伤害、射速、B 键聚气速度（未满级时每次必出，满级约 18 秒一次）、星爆后的无敌时间（每级 +1 秒，最多 3 级即 6 秒）、移速、掉落、吸附范围、每波护盾、死亡保留一半弹种等级、夺舍强化、恢复生命）。暂停菜单会列出已获得的强化。
- **连击与擦弹**：连续击毁敌机累积连击，得分倍率最高 ×3，约 2.6 秒不击毁或被击中则清零；敌弹贴身掠过算擦弹，奖励少量得分和星爆能量。
- **弹种**：标准弹（1→5 路并列）、**激光弹**（高速光束，穿透整列敌机）、**锁定弹**（每发自动锁定不同目标并转向追踪）、**爆破弹**（命中后范围爆炸，同时清除附近敌弹）。
  拾取对应道具即切换到该弹种并升一级（最高 5 级）；**每种弹各自记录等级，吃了其他弹种的道具也不会改变原来弹种的等级**。
  也可点击 HUD 上的弹种标签（标 / 激 / 锁 / 爆，显示各自等级）或按键盘 1-4 手动切换。
- **导弹吊舱**：附件道具，机身两侧各挂一个吊舱，按住射击时交替发射**跟踪小导弹**，可升到 3 级，与当前弹种无关。
- **其他道具**：护盾、速度提升（移速和射速）、生命 +1。受伤只扣命，不降弹种等级；但**死亡（生命耗尽）后，所有弹种等级和导弹吊舱清零**。
- **受击判定**：命中判定是贴合机身的椭圆（机身加内侧机翼），被击中时扣命，并有红色闪屏、震屏和震动反馈。
- **生命 / 得分 / 高分榜**：击毁和过波加分，前 10 名保存在浏览器 `localStorage`。
- **灵魂模式**：生命耗尽后化为灵魂（不能射击、免疫子弹）。撞向任意空中敌机即可**夺舍**，操控这架敌机并获得它的技能——射速大幅提升（每种敌机的技能不同，例如运输机「货舱机炮」血厚并且道具吸附范围加倍，无人机母舰发射追踪导弹，闪电机高速穿透连射），此时 B 键变为「超载」。
  **魂能不会随时间减少**：灵魂形态下可以从容寻找目标，只有夺舍的飞机被击毁时才消耗 34 点魂能（变回灵魂），魂能耗尽则游戏结束；击毁敌机可回复魂能。拾取生命道具可**复活**。
  Boss、陨石和地面部队无法被夺舍；灵魂形态下如果场上没有可夺舍的敌机（例如只剩 Boss），敌方会派来增援，保证总有夺舍机会。

## 技术说明

- 游戏逻辑（移动、碰撞、敌波、Boss、道具、灵魂夺舍等）在一个 360 宽的二维平面上计算；画面全部交给 Three.js：透视镜头向前倾斜 37°，飞行平面上的位置和屏幕位置一一对应，所以手感和判定与画面一致。
- 飞机、敌机、Boss、地面部队都是用拉伸多边形和基本几何体拼成的低多边形模型；地形是带起伏和顶点颜色的网格，随前进方向循环滚动；树木、岩石、高楼等地物用实例化网格绘制；子弹和粒子各用一次绘制调用。
- 分数、血条、提示文字等界面元素画在 3D 画面上方的一层 2D 画布上。
- 音效全部用 WebAudio 实时合成，没有音频文件。

## 调试

URL 加 `?debug` 会在 `window.__g` 暴露游戏状态和少量调试函数（用于自动化测试）。
