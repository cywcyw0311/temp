# 星际突击 · STAR RAID

手机竖屏的自上而下太空射击游戏。单文件 `index.html`，无需构建、无外部依赖。

作者：蔡蕴文

## 运行

直接用浏览器打开 `index.html`，或在目录下起一个静态服务：

```bash
python3 -m http.server 8000   # 手机和电脑同一网络时访问 http://<电脑IP>:8000
```

桌面浏览器会以居中的竖屏比例显示，并支持键盘。

## 操作

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| 方向圆盘 | 左下角 | 模拟量移动，带惯性，平滑转向；机身中心可到屏幕边缘（半个机身出屏），能打到边缘的敌机 |
| **A** 射击 | 右下角 | 按住射击；**长按约 0.5 秒锁定连发**，锁定后**再按一次解除** |
| **B** 技能 | 右下角（A 正上方） | 能量满后释放「星爆」冲击波：清除敌弹并重创范围内敌机 |
| 暂停 ⏸ | 右上角 | 暂停菜单：继续 / 重新开始 / 高分榜 / 音效开关 / 返回主菜单 |

键盘：方向键或 WASD 移动，Space/J 射击，L 锁定连发，B/K/Shift 技能，1-4 切换弹种，P/Esc 暂停。

## 玩法

- **敌波**：共 9 种敌机和 Boss（每 5 波一个），多种编队（弧形、横排、V 形、悬停、俯冲）。新敌机会在指定波次首次登场，并有名称提示：
  - 基础：侦察机、战斗机、重型炮艇、俯冲镖。
  - **狙击机**（第 3 波起）：悬停蓄力，出现红色瞄准线，最后 0.2 秒锁定方向后射出高速重弹。
  - **布雷机**（第 4 波起）：横穿屏幕投放水雷，水雷闪烁后爆裂成一圈子弹，可以提前击落。
  - **护盾舰**（第 6 波起）：先要打破护盾，护盾被击中和破碎都有专属音效。
  - **导弹艇**（第 7 波起）：发射追踪导弹，导弹可被击落。
  - **激光舰**（第 8 波起）：蓄能时地面出现红色预警线，随后喷出竖直光束，站在光束下会受伤。
- **弹种**：标准弹（1→5 路并列）、**激光弹**（高速光束，穿透整列敌机）、**锁定弹**（每发自动锁定不同目标并转向追踪）、**爆破弹**（命中后范围爆炸，同时清除附近敌弹）。
  拾取对应道具即切换到该弹种并升一级（最高 5 级）；**每种弹各自记录等级，吃了其他弹种的道具也不会改变原来弹种的等级**。
  也可点击 HUD 上的弹种标签（标 / 激 / 锁 / 爆，显示各自等级）或按键盘 1-4 手动切换。
- **导弹吊舱**：附件道具，机身两侧各挂一个吊舱，按住射击时交替发射**跟踪小导弹**，可升到 3 级（更快、更痛），与当前弹种无关。
- **其他道具**：护盾、速度提升（移速和射速）、生命 +1。弹种等级和吊舱只由道具决定，受伤、变灵魂、复活都不会降低它们。
- **受击判定**：命中判定是贴合机身的椭圆（机身加内侧机翼），被击中时扣命，并有红色闪屏、震屏和震动反馈。
- **生命 / 得分 / 高分榜**：3 条命（最多 5），击毁和过波加分，前 10 名保存在浏览器 `localStorage`。
- **灵魂模式**：生命耗尽后化为灵魂（不能射击、免疫子弹）。撞向任意敌机即可**夺舍**，操控这架敌机并获得它的技能——射速大幅提升
  （侦察机连射、战斗机双联速射、炮艇散射、镖机穿刺光矢，狙击机穿甲速射、布雷机四联散射、护盾舰连射并带走护盾、导弹艇追踪导弹、激光舰激光连射），
  此时 B 键变为「超载」。**魂能不会随时间减少**：灵魂形态下可以从容寻找目标，只有夺舍的飞机被击毁时才消耗 34 点魂能（变回灵魂），
  魂能耗尽则游戏结束；击毁敌机可回复魂能。拾取生命道具可**复活**。Boss 无法被夺舍。
- **视觉**：三层视差星空 + 星云 + 缓慢掠过的行星（会随飞机左右位移产生视差，加速时星流变快）、枪口闪光、爆炸粒子与冲击波。

## 调试

URL 加 `?debug` 会在 `window.__g` 暴露游戏状态和少量调试函数（用于自动化测试）。
