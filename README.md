# 星际突击 · STAR RAID

手机竖屏的自上而下太空射击游戏。单文件 `index.html`，无需构建、无外部依赖。

作者：蔡蕴文

## 运行

直接用浏览器打开 `index.html`，或在目录下起一个静态服务：

```bash
python3 -m http.server 8000   # 手机和电脑同一网络时访问 http://<电脑IP>:8000
```

桌面浏览器会以居中的竖屏比例显示，并支持键盘。

## 操作

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| 方向圆盘 | 左下角 | 模拟量移动，带惯性，平滑转向；机身中心可到屏幕边缘（半个机身出屏），能打到边缘的敌机 |
| **A** 射击 | 右下角 | 按住射击；**长按约 0.5 秒锁定连发**，锁定后**再按一次解除** |
| **B** 技能 | 右下角（A 正上方，A/B 半透明，飞机经过时更透明） | 能量满后释放「星爆」冲击波：清除敌弹并重创范围内敌机 |
| 暂停 ⏸ | 右上角 | 暂停菜单：继续 / 重新开始 / 高分榜 / 音效开关 / 返回主菜单 |

键盘：方向键或 WASD 移动，Space/J 射击，L 锁定连发，B/K/Shift 技能，1-4 切换弹种，P/Esc 暂停。

## 玩法

- **难度**：主菜单可选 简单 / 中等 / 困难（会记住上次选择）。简单 5 条命、敌机更脆、敌弹更慢、掉落更多；中等 4 条命；困难 3 条命、敌机更多更硬、敌弹更快。高分榜会标注难度。

- **星区与敌波**：每 5 波是一个星区（深空航道、赤色星云、翡翠裂隙、紫晶回廊、黄金日冕，循环），背景配色和布景各不相同，第 5 波是该星区的 Boss。共 18 种敌机，新敌机在指定波次首次登场并有名称提示：
  - 基础：侦察机、战斗机、重型炮艇、俯冲镖。
  - **狙击机**（第 3 波起）：悬停蓄力，出现红色瞄准线，最后 0.2 秒锁定方向后射出高速重弹。
  - **布雷机**（第 4 波起）：横穿屏幕投放水雷，水雷闪烁后爆裂成一圈子弹，可以提前击落。
  - **护盾舰**（第 6 波起）：先要打破护盾，护盾被击中和破碎都有专属音效。
  - **导弹艇**（第 7 波起）：发射追踪导弹，导弹可被击落。
  - **激光舰**（第 12 波起）：蓄能时出现红色预警线，随后喷出竖直光束，站在光束下会受伤。
  - **分裂机**（第 2 波起）：被击毁后分裂成两架侦察机。
  - **冲锋舰**（第 6 波起）：在屏幕一侧对准你的高度，红色横线预警后高速横向冲撞。
  - **隐形机**（第 8 波起）：隐身时无法被锁定和命中，现身后扇形齐射。
  - **旋涡机**（第 11 波起）：周期性喷出旋转的螺旋弹幕。
  - **蜂群机**（第 4 波起）：成群追踪玩家的小型自杀机。
  - **浮游炮台**（第 7 波起）：旋转着向四个方向开火。
  - **修复机**（第 12 波起）：用光束修复附近受损的敌机，应优先击落。
  - **引力机**（第 13 波起）：把玩家拉向自己，并发射缓慢的重力弹。
  - **陨石**（第 3 波起）：可击碎的障碍，会碎成两块，不能夺舍。
  - **精英 ★**（第 3 波起随机出现）：体型更大、更耐打、火力更密，得分 ×3，必掉道具。
  - 其余敌机的登场波次：布雷机 6、护盾舰 8、隐形机 9、导弹艇 11、旋涡机 14、激光舰 16。难度随波次提升。
- **Boss**：四种，按星区轮换，半血后进入狂暴（出招更快并解锁额外能力），被击败时清空全屏敌弹。
  - **赤焰主宰**：扇形弹、环形弹、三连点射；狂暴后两侧持续弹雨。
  - **虚空织网者**：带预警的竖直光束、抛射水雷、双层蛛网弹；狂暴后会瞬移。
  - **蜂巢母舰**：放出蜂群机、追踪导弹、螺旋弹幕。
  - **裂空者**：留缺口的弹墙、对准玩家俯冲、霰弹。
- **强化**：每击败一个 Boss，从三个随机强化里选一个，本局有效（伤害、射速、B 键聚气速度（未满级时每次必出）、移速、掉落、吸附范围、每波护盾、死亡保留一半弹种等级、夺舍强化、恢复生命）。暂停菜单会列出已获得的强化。
- **连击与擦弹**：连续击毁敌机累积连击，得分倍率最高 ×3，约 2.6 秒不击毁或被击中则清零；敌弹贴身掠过算擦弹，奖励少量得分和星爆能量。
- **弹种**：标准弹（1→5 路并列）、**激光弹**（高速光束，穿透整列敌机）、**锁定弹**（每发自动锁定不同目标并转向追踪）、**爆破弹**（命中后范围爆炸，同时清除附近敌弹）。
  拾取对应道具即切换到该弹种并升一级（最高 5 级）；**每种弹各自记录等级，吃了其他弹种的道具也不会改变原来弹种的等级**。
  也可点击 HUD 上的弹种标签（标 / 激 / 锁 / 爆，显示各自等级）或按键盘 1-4 手动切换。
- **导弹吊舱**：附件道具，机身两侧各挂一个吊舱，按住射击时交替发射**跟踪小导弹**，可升到 3 级（更快、更痛），与当前弹种无关。
- **其他道具**：护盾、速度提升（移速和射速）、生命 +1。受伤只扣命，不降弹种等级；但**死亡（生命耗尽）后，所有弹种等级和导弹吊舱清零**。
- **受击判定**：命中判定是贴合机身的椭圆（机身加内侧机翼），被击中时扣命，并有红色闪屏、震屏和震动反馈。
- **生命 / 得分 / 高分榜**：3 条命（最多 5），击毁和过波加分，前 10 名保存在浏览器 `localStorage`。
- **灵魂模式**：生命耗尽后化为灵魂（不能射击、免疫子弹）。撞向任意敌机即可**夺舍**，操控这架敌机并获得它的技能——射速大幅提升
  （侦察机连射、战斗机双联速射、炮艇散射、镖机穿刺光矢，狙击机穿甲速射、布雷机四联散射、护盾舰连射并带走护盾、导弹艇追踪导弹、激光舰激光连射），
  此时 B 键变为「超载」。**魂能不会随时间减少**：灵魂形态下可以从容寻找目标，只有夺舍的飞机被击毁时才消耗 34 点魂能（变回灵魂），
  魂能耗尽则游戏结束；击毁敌机可回复魂能。拾取生命道具可**复活**。Boss 无法被夺舍；灵魂形态下如果场上没有可夺舍的敌机（例如只剩 Boss），敌方会派来增援，保证总有夺舍机会。
- **视觉**：分形噪声星云、各星区专属布景（行星与星系、战舰残骸和交战闪光、翡翠晶簇、空间站构件、恒星日冕）、三层视差星空、碎石带、流星；机体带立体明暗，翼尖光颜色随当前弹种变化（会随飞机左右位移产生视差，加速时星流变快）、枪口闪光、爆炸粒子与冲击波。

## 调试

URL 加 `?debug` 会在 `window.__g` 暴露游戏状态和少量调试函数（用于自动化测试）。
